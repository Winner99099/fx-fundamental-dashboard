How to read changes

Changes are shown as actual minus previous, with percentage-point notation for percentage-based releases. GDP units and employment units follow the published series. Missing dates or actual figures are shown as unverified rather than guessed. A revision is not treated as a new release.

Scoring methodology

The structural score remains a slower-moving relative macro comparison. Event momentum scores released actual-versus-consensus surprises only, with indicator-aware direction (for example, hotter inflation is treated as a short-term hawkish policy surprise), High/Medium/Low impact weighting and a 36-hour half-life. The short-term score is 60% structural + 40% event momentum, shown only when verified event data exists. This is not yet a market-implied rate-path or FX-price-confirmed model.

STEP 3 · THE CONCLUSION

Fundamental bias cards

Each card explains direction, macro drivers, validity, invalidation and the technical setup to wait for. Signals use verified currency scores; missing inputs are never guessed.

How bias is derived

Bias = base short-term score minus quote short-term score. Above +0.35 is bullish, below −0.35 is bearish, between them is neutral. This is a relative macro read, not a price forecast.
